The unpinned install script (curl -fsSL https://k3sm.io/install.sh | sh) always resolves the newest row here. Set K3SM_INSTALL_VERSION to the version column to pin an older release instead — see install for every channel and upgrades for moving between them.

Verifying a Download by Hand#

The install script already verifies the sha256 before it runs anything. To check a downloaded tarball yourself:

shasum -a 256 k3sm_<version>_darwin_arm64.tar.gz

Compare the output against the sha256 in the assets column above (open the “sha256” disclosure), or against the checksums file linked there — the same file the script checks against.
