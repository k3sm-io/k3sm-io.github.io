Older releases stay installable the same way and are listed on prior releases.

The unpinned install script (curl -fsSL https://k3sm.io/install.sh | sh) resolves the newest stable release here, skipping any row marked pre-release. Set K3SM_INSTALL_VERSION to the version column to pin an older release instead. See install for every channel and upgrades for moving between them.

Verifying a Download by Hand#

The install script already verifies the sha256 before it runs anything. To check a downloaded tarball yourself:

shasum -a 256 k3sm_<version>_darwin_arm64.tar.gz

Compare the output against the sha256 in the assets column above (open the “sha256” disclosure), or against the checksums file linked there, which is the same file the script checks against. The same file has a line for the disk image; download shows that check.
