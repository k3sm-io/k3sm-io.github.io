Download

The k3sm app for Mac: a disk image that installs and manages k3sm.

Download for Mac

Version 0.2.3 (289 MB) for Apple silicon and macOS 26 or newer, Developer ID signed and notarized by Apple.

Prefer the terminal? Use the install script.

Installing the App#

The disk image opens to one window: k3sm.app beside a shortcut to your Applications folder.

  1. Open the downloaded .dmg.
  2. Drag k3sm.app onto Applications.
  3. Open k3sm from Applications.
  4. Choose to start a cluster on this Mac or join one another Mac runs, then answer one administrator prompt, and the app sets up k3sm.

The app does not update itself in this release. A new version is a new download from this page.

Checking the Download#

Each release publishes a checksums file beside the disk image, and the disk image has a line in it. Hash the file you downloaded:

shasum -a 256 k3sm_<version>_darwin_arm64.dmg

The output must match the line for k3sm_<version>_darwin_arm64.dmg in that release’s checksums file, linked from releases. The image is also Developer ID signed and notarized by Apple.

Installing from the Terminal#

The install script installs the same k3sm without the app:

curl -fsSL https://k3sm.io/install.sh | sh

install covers what the script does, pinning a version, and the other channels.
